# Overview

> Every control you can put in a tab. Each one returns an object you can read and change later.

- [Toggle](https://martinikaws.github.io/GainUI/md/elements-toggle.md): On/off switch
- [Slider](https://martinikaws.github.io/GainUI/md/elements-slider.md): A number in a range
- [Button](https://martinikaws.github.io/GainUI/md/elements-button.md): Runs a function
- [Dropdown](https://martinikaws.github.io/GainUI/md/elements-dropdown.md): One or many options
- [Textbox](https://martinikaws.github.io/GainUI/md/elements-textbox.md): Typed text
- [Keybind](https://martinikaws.github.io/GainUI/md/elements-keybind.md): Rebindable keys
- [Colorpicker](https://martinikaws.github.io/GainUI/md/elements-colorpicker.md): H, S, V, swatches, hex
- [Tabs & Sections](https://martinikaws.github.io/GainUI/md/elements-tab.md): Pages and groups
- [Label & Paragraph](https://martinikaws.github.io/GainUI/md/elements-label.md): Wrapped text
- [Image](https://martinikaws.github.io/GainUI/md/elements-image.md): From a link or bytes
- [Notifications](https://martinikaws.github.io/GainUI/md/window-notify.md): Slide-in messages
- [Saving & Flags](https://martinikaws.github.io/GainUI/md/window-saving.md): Remembered between runs

All elements share the same methods: [Element methods](https://martinikaws.github.io/GainUI/md/elements-methods.md).
